## 移動速度
対象時刻から24時間後までに同一天体が移動した黄経距離を計算し、リリーが記載した24時間平均移動量に対して速いか遅いかで点数を付与する。速度の判定には移動量の絶対値を用い、順行・逆行の方向はこの項目では評価しない。

| 対象 | 点数 |
| --- | --- |
| 平均より速い | +2 |
| 平均より遅い | -2 |
| 平均と等しい | 0 |

| 火星 | 0°31′27″ | 0.524167° |
| 太陽 | 0°59′08″ | 0.985556° |
| 金星 | 0°59′08″ | 0.985556° |

## 太陽に対するオリエンタル・オキシデンタル
太陽は判定しない。  

黄経度数を基準に、`(天体黄経 - 太陽黄経) mod 360` で太陽から天体への黄経差を計算します。  
黄経差が 0〜180度未満であればオキシデンタル、180〜360度未満であればオリエンタルとなります。  
ただし、太陽とのコンジャクションしており、かつ度数差が1度以内である場合は、完全な合とみなしてこの判定はされないものとする。  
また、180度の境界ではオリエンタル側を優先してください。

例A）木星30度、太陽230度
30-230=-200度、360度へ正規化すると160度なので、オキシデンタルの判定となります。

例B）水星230度、太陽20度
230-20=210度なので、オリエンタルの判定となります。

また、天体によってオリエンタル・オキシデンタルでの配点が異なります。以下の表通りに配転してください。

| 天体 | オリエンタル点数 | オキシデンタル点数 |
| --- | --- | --- |
| 火星、木星、土星 | +2 | -2 |
| 水星、金星、月 | -2 | +2 |

## 太陽光線下
太陽は対象外とする。

対象天体と太陽の度数差を計算し、以下の表に従って点数を付与する。（この項目ではオリエンタル・オキシデンタルは関係なくどちらにいても純粋な度数差で判別する）

| 名称 | 度数範囲 | 点数 |
| --- | --- | --- |
| カジミ | 0度0分〜0度17分 | +5 |
| コンバスト | 0度17分〜8度30分 かつ 太陽と同一サイン内 | -5 | 
| アンダー・ザ・サンビーム | 0度00分〜17度00分 | -4 |
| 太陽光線外 | 17度以上 | +5 |  

太陽光線下の判定は表の上から順に判定してください。  
コンバストは対象天体が太陽と同一サイン内であることが条件となるため、仮にコンバストの度数範囲内でもサインが異なれば、アンダー・ザ・サンビーム側の判定に落ちます。
この場合、採点結果の説明には「太陽とはサイン違いのためコンバスト不成立」と注記します。

## 火星・土星に挟まれる関係性
火星、土星は対象外。  

前提として、チャート上の火星と土星が以下の関係性にある場合のみ判定となる。
* 火星と土星の度数差が6度以内であること（00分一致まで含む）

チャート上の条件が成立する場合に、対象天体が以下の条件を満たす場合に -5 を付与する。
* 対象天体が火星と土星間の度数に位置すること
* サインは異なってもbetweenは成立するとみなす

火星と土星の度数差の計算は横径を利用し、片側が360度を超える場合を想定して以下のような計算式を用いる。

```
difference = abs(a - b)
shortest_distance = min(difference, 360.0 - difference)
```
shortest_distanceは最短角距離として度数差の判定に利用できる。
