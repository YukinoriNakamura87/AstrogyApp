# リリー採点実装仕様 エッセンシャル
* 採点に利用するハウス方式は、計算対象のチャートのハウス方式に準拠する。（伝統的にはレギオモンタナスのみだが、このアプリ上では採点方式を採用したリリー準拠方式という位置付けとする）
* チャートとは独立した計算ライブラリとして実装する。（どのようなチャートに対しても使えるようにしておく）
* 採点及び関係性を示す天体は太陽・月・水星・金星・火星・木星・土星の7天体とする。（天王星・海王星・冥王星・ノードは含まれない）
* 各品位は、 `リリー式品位表.md` を使うこと。また各品位表は、流派や今後の研究によって差し替える可能性があるためロジックとは独立したデータで管理するように実装してください。

## エッセンシャル

### 採点対象となる要素
* ドミサイル・エグザルテーション・デトリメント・フォール
* トリプリシティ（チャートセクトで区別、リリー式に従い水の場合のみ昼夜とも火星の支配とする）
* ターム（プトレマイオス式）
* フェイス
* ペレグリン
* ミューチュアルレセプションによるディグニティ

### 基本ロジック
1. 対象天体単独のディグニティ・デビリティを判定。
2. ペレグリン判定
3. チャート上の他天体に対して、ミューチュアルレセプションを判定。

### 基本品位の仕様

| 点数 | 品位 |
| --- | --- |
| +5 | ドミサイル |
| +4 | エグザルテーション |
| -5 | デトリメント |
| -4 | フォール |

### トリプリシティの仕様

セクトは、太陽が1〜6ハウス在室なら夜、7〜12ハウス在室なら昼とする。  

基本はリリー式のトリプリシティ表を使う。通常のトリプリシティに水だけは昼夜ともに火星の支配とする形になる。

対象天体が、配置サインのトリプリシティのセクト支配星に含まれていれば +3 とする。

例）太陽4H、判定天体=木星 牡羊座 
夜のセクト、牡羊座は火のエレメント。  
火は、昼=太陽、夜=木星 であるため、夜の支配星として +3 とする。

### タームの仕様
該当すれば +2 とする。  

プトレマイオス式ターム表を使用する。（別途参照）  

度数判定は、終了度数を未満として扱う判定にする。   
判定式：ターム度数 <= 対象天体 < 次のターム度数 

例）牡羊座 木星 6度00分00秒
金星のタームとして、±0 とする。
牡羊座は、木星 0度00分00秒〜6度00分00秒  
金星 6度00分00秒〜14度00分00秒  
の範囲のため、 金星ターム <= 木星 に該当しタームは成立しない。

### フェイスの仕様
該当すれば +1 とする。

フェイス表を採用する。(別途参照)


### ペレグリンの仕様
該当すれば -5 とする。

怒ミサイル・エグザルテーション・トリプリシティ・ターム・フェイス、いずれにも該当しない場合、ペレグリンの点数を適用する。

なお、デトリメント・フォールが該当してもペレグリンは適用される。

例）土星　牡羊座 6度00分 セクト=昼
フォールなので-4、加点品位が該当しないためペレグリン-5

### ミューチュアル・レセプションの使用について

* 対象天体の所属サインの支配星・エグザルテーションの対象天体をそれぞれ確認して判定する。
* ドミサイル・エグザルテーションは、対象天体が重複成立する場合でもどちらも加算される。
* 比較対象の天体が自分自身となってしまう場合は、ドミサイル・エグザルテーションともに判定しない。

**重複成立のパターン例**
A天体・・・水星 牡牛座
B天体・・・金星 双子座
C天体・・・月 乙女座

この場合、A天体はB天体とはドミサイルによるミューチュアルレセプションを形成する一方、C天体ともエグザルテーションによるミューチュアルレセプションが成立します。  
これは重複加算対象となり、 +5,+4が付与されます。

#### ドミサイル
該当すれば +5 とする。

対象天体（A天体）のサインの支配星（B天体）をチャート上で確認し、B天体の配置サインがA天体のドミサイルである場合、どミサイルによるミューチュアルレセプションと判定し、加点対象とする。

例）
A天体・・・太陽 牡羊座
B天体・・・火星 獅子座
C天体・・・土星 獅子座

この場合、A天体とB天体は互いのドミサイルを交換し合っている配置のため、ミューチュアルレセプションが成立する。  
※ 太陽は追加でエグザルテーションも受ける。

A天体とC天体では、C天体→A天体はドミサイルになるが、A天体→C天体はドミサイルではないため、ミューチュアルレセプションは成立しない。

#### エグザルテーション
該当すれば +4 とする。

対象天体（A天体）のサインのエグザルテーションに属する星（B天体）をチャート上で確認し、B天体の配置サインがA天体のエグザルテーションである場合、エグザルテーションによるミューチュアルレセプションと判定し、加点対象とする。

例）
A天体・・・太陽 蟹座
B天体・・・木星 牡羊座
C天体・・・火星 牡羊座

A天体とB天体はエグザルテーションを交換し合っているので、エグザルテーションによるミューチュアルレセプションが成立します。  
A天体とC天体は、C天体からはA天体の所属サインはエグザルテーションですが、A天体のサインはC天体の火星がフォールなので成立しません。
